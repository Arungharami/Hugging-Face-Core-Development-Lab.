# Explainable Fraud Risk Intelligence

An interactive, transparent financial risk decision support interface demonstrating explainable machine learning for transaction assessment.

## Responsible AI & Ethical Framework

> **Important Notice:** This system is an educational and research decision support tool. It does **NOT** make definitive accusations of fraud or legal guilt. All outputs present statistical pattern risk levels intended to assist authorized human analysts.
